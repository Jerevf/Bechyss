# Bechyss

Sitio web informativo y comercial para **Bechyss**, una marca de pan de masa madre artesanal ubicada en Tibas, San Jose, Costa Rica.

El proyecto presenta una landing page responsive con catalogo de sabores, informacion sobre beneficios, conservacion del pan y enlaces directos para realizar pedidos por WhatsApp.

## Vista general

La pagina esta construida con tecnologias web basicas:

- HTML5
- CSS3
- JavaScript vanilla
- Google Fonts
- Font Awesome
- Render para el despliegue
- GPT-5.5 como apoyo en el desarrollo

No requiere frameworks, dependencias externas instaladas ni proceso de compilacion.

## Caracteristicas

- Landing page responsive para escritorio y dispositivos moviles.
- Menu de navegacion con enlaces internos.
- Seccion principal tipo hero para presentar la marca.
- Catalogo de panes con imagenes, ingredientes, precios y botones de pedido.
- Tarjetas interactivas con efecto flip.
- Seccion de beneficios del pan de masa madre.
- Guia de conservacion con pestanas interactivas.
- Animaciones al hacer scroll.
- Contadores animados.
- Enlaces directos a WhatsApp con mensajes prellenados.

## Como abrir el proyecto

Puedes abrir el sitio directamente desde el navegador:

```text
proyecto/index.html
```

Tambien puedes ejecutarlo con un servidor local. Por ejemplo, desde la carpeta `proyecto`:

```bash
python -m http.server 8000
```

Luego abre:

```text
http://localhost:8000
```

## Despliegue

El proyecto utiliza **Render** como plataforma de despliegue, permitiendo publicar el sitio web para que pueda ser visitado en linea.

## Apoyo con inteligencia artificial

Durante el desarrollo del proyecto se utilizo **GPT-5.5** como herramienta de apoyo para la creacion, organizacion y mejora del codigo y la documentacion.

## Archivos principales

- `proyecto/index.html`: estructura principal del sitio.
- `proyecto/styles.css`: estilos visuales, layout responsive y animaciones.
- `proyecto/script.js`: interacciones del menu, tarjetas, tabs, particulas y contadores.
- `proyecto/images/`: imagenes utilizadas en la pagina.
